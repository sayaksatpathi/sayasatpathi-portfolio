## Overview

A single-page personal portfolio introducing me and my work. It flows from a welcoming hero into focused sections covering who I am, what I've built, what I write about, what I've achieved, what I'm learning, and the tools I use.

## 📄 Sections

- 👋 **Hi, I'm Sayak** — intro hero
- 🧑 **About Me**
- 💼 **Projects**
- ✍️ **Blog**
- 🏆 **Achievements**
- 📚 **Learning**
- 🧰 **Tech Stack**

## 🧱 Tech Stack

- Static **HTML + CSS + JavaScript**, self-contained in `index.html`
- Includes a `SECURITY.md` policy
- Deployed on **Vercel**

## 🚀 Run Locally

```bash
npx serve .          # or open index.html directly
```
